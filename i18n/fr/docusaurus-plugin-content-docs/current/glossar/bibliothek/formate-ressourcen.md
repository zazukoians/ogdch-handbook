# Formate für Ressourcen

## Zulässige Dateiformate für Ressourcen

Auf opendata.swiss unterstützen wir eine Auswahl an Dateiformaten.
Hier finden Sie eine Auflistung aller zulässigen Dateiformate.
Falls Sie Ihr Format in dieser Liste nicht wiederfinden,
[können Sie sich an uns wenden](mailto:opendata@bfs.admin.ch)
und wir fügen es gerne hinzu.

### Strukturierte Daten

<a id="term-Comma-Separated-Values-CSV"></a>

Comma Separated Values (CSV)
: [RFC 4180](https://tools.ietf.org/html/rfc4180)

<a id="term-JavaScript-Object-Notation-JSON"></a>

JavaScript Object Notation (JSON)
: [RFC 4627](https://tools.ietf.org/html/rfc4627)

<a id="term-Extensible-Markup-Language-XML"></a>

Extensible Markup Language (XML)
: [W3C REC](http://www.w3.org/TR/2008/REC-xml-20081126)

<a id="term-Resource-Description-Framework-RDF"></a>

Resource Description Framework (RDF)
: [W3C REC](https://www.w3.org/TR/?tag=data)

### Text

<a id="term-Text-TXT"></a>

Text (TXT)
: [ISO Latin-1 (ISO 8859-1)](https://www.iso.org/standard/28245.html)

oder ISO/IEC 646:1991-IRV): [ISO/IEC 646-US:1991](https://www.iso.org/standard/4777.html)

Office Open XML Document (DOCX)
: [ISO/IEC 29500](https://www.iso.org/standard/51463.html)

<a id="term-Open-Document-Text-ODT"></a>

Open Document Text (ODT)
